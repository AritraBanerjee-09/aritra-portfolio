## 🚀 Getting Started (Local Development)

### Prerequisites
Make sure you have **Node.js** (v18+) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AritraBanerjee-09/aritra-portfolio.git
   cd aritra-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000/` to view the website locally.

---

## 📦 Production Build

To compile a static production bundle:

```bash
npm run build
```

The output files will be generated in the `dist/` directory, ready to be deployed to Vercel, Netlify, or GitHub Pages.

---

## 🌐 Deploying to Vercel (1-Click)

1. Push changes to `main` branch.
2. Import repository `AritraBanerjee-09/aritra-portfolio` in [Vercel](https://vercel.com).
3. Click **Deploy**.
